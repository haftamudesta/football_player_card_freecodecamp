# Football Card Builder <a name="about-project"></a>

**Football Card Builder** is an interactive web application that allows users to create and customize their own football player cards in real-time. Built with React, TypeScript, and Vite, this application features dynamic form inputs, live preview updates, localStorage persistence, and a responsive design inspired by popular football video games like FIFA/EA FC.

### Key Features <a name="key-features"></a>

- **Real-time Card Preview** - See changes instantly as you type
- **Customizable Player Attributes** - Edit name, position, overall rating, club, and image URL
- **Six Core Stats** - PAC, SHO, PAS, DRI, DEF, PHY (Pace, Shooting, Passing, Dribbling, Defense, Physical)
- **Dynamic Tier System** - Cards automatically display Elite, Gold, Silver, or Bronze tier based on overall rating
- **Position Selection** - Choose from 11 different football positions (GK, CB, LB, RB, CDM, CM, CAM, LW, RW, ST, CF)
- **LocalStorage Persistence** - Your custom cards are saved automatically and persist after page reload
- **Responsive Design** - Optimized for desktop, tablet, and mobile devices
- **Type Safety** - Full TypeScript implementation with strict typing
- **Error Handling** - Graceful error handling for localStorage operations

## 💻 Getting Started <a name="getting-started"></a>

To get a local copy up and running, follow these steps.

### Prerequisites

In order to run this project you need:

- [ ] Node.js (v18 or later)
- [ ] NPM or Yarn package manager
- [ ] Git installed
- [ ] A modern web browser

### Setup

Clone this repository to your desired folder:

```bash
git clone https://github.com/haftamudesta/football-card-builder.git
```

```
cd football-card-builder
```

- [ ] Open the file in your code editor

```
code .
```

### Install dependencies:

- [ ] Node modules:

```
npm install
```

### Usage

To run the project, execute the following command:

```
npm run dev
```
